ADIE Manifest Verifier v6 (witness evaluation)

Offline. No network. No external dependencies. Ed25519 / manifest_version 1.0.

Browser check: needs Ed25519 in Web Crypto API. Supported: Chrome 113+, Firefox 130+, Safari 17+.
Trust model: Public key embedded in manifest but pinned against TRUSTED_KEY_IDS. Untrusted key_id → rejected.

Witness evaluation (v6)

Evaluates Z3 witnesses against their policy DSL, in-browser. No Z3, no WASM, no network. Each ACCEPT witness is evaluated; pre-gate and trusted-boundary cases are displayed, not evaluated.

Checks:
  1. Structural validation
  2. Key identity pinning (key_id vs TRUSTED_KEY_IDS)
  3. RFC 8785 JCS canonicalization
  4. SHA-256(canonical) == signed_payload_sha256
  5. Ed25519 signature valid
